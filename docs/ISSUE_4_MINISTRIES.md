# Issue #4: адаптация вкладки институтов / министерств

Источник запроса: Steam Workshop `3746723955`, **Persistent Assets**.

## Что подтверждено исходным модом

В описании Persistent Assets явно указано:

- School и Hospital являются физическими зданиями;
- они дают штату эффекты Education и Healthcare institutions;
- глобальные эффекты этих институтов уменьшены вдвое.

Поэтому в `0.2.0` перенесен именно этот институциональный слой. Остальные системы Persistent Assets (housing, streets, industrial/commercial space, private construction и т. п.) не импортируются.

## Реализация для Victoria 3 1.13.11

### Министерства

Вкладка `Institutions` локализована как `Министерства`.

Ванильные институты переименованы без изменения их базовой логики:

- Colonial Affairs -> Министерство колониальных дел;
- Education -> Министерство образования;
- Social Security -> Министерство социальной защиты;
- Workplace Safety -> Министерство труда;
- Law Enforcement -> Министерство правопорядка;
- Health System -> Министерство здравоохранения;
- Home Affairs -> Министерство внутренних дел.

### Образование

Для Religious / Private / Public Schools глобальный `institution_modifier` уменьшен на 50% через аддитивный `INJECT`.

Добавлено здание `building_vicmod_school`.

Его Production Method автоматически определяется действующим законом об образовании и возвращает штату локальную половину соответствующих эффектов. Эффект `workforce_scaled`, поэтому незаполненная школа не дает полный бонус.

### Здравоохранение

Для Charitable / Private / Public Healthcare глобальный `institution_modifier` уменьшен на 50% через аддитивный `INJECT`.

Добавлено здание `building_vicmod_hospital`.

Production Method зависит от действующего закона о здравоохранении и возвращает локальную половину соответствующих state-модификаторов. Эффект также зависит от занятости здания.

## Почему используется INJECT

В Victoria 3 1.12+ modifier-блоки при `INJECT` складываются с ванильными. Поэтому для снижения эффекта вдвое достаточно инъектировать противоположную половину исходного значения. Это позволяет не копировать целиком `01_education_system.txt` и `01_health_system.txt` и уменьшает риск конфликтов с текущей 1.13.x.

## Ограничение адаптации

Архив, приложенный к GitHub issue, хранится как GitHub `user-attachments` и недоступен текущему GitHub API-коннектору для скачивания. Поэтому перенос основан на публично подтвержденном функционале именно Workshop item `3746723955` и актуальных vanilla-файлах Victoria 3 1.13.11, а не на побайтовом копировании старого архива.

## Smoke test

1. Проверить запуск игры и `error.log`.
2. Проверить название вкладки `Министерства`.
3. Проверить доступность School при активном Education institution level > 0.
4. Проверить доступность Hospital при активном Healthcare institution level > 0.
5. Проверить автоматическое соответствие PM действующему закону.
6. Сравнить глобальные institution modifiers с ванилью: они должны быть ровно вдвое меньше.
7. Проверить, что полностью занятый уровень School/Hospital возвращает локальную половину одного уровня соответствующего института.
8. Проверить смену закона Education/Healthcare на уже построенных зданиях.
